# 📊 Data Analyst Portfolio — Streamlit App

Interactive portfolio built with Python + Streamlit, featuring live charts and project case studies.

## 🚀 Quick start

```bash
# 1. Clone / download this folder
# 2. Install dependencies
pip install -r requirements.txt

# 3. Run locally
streamlit run app.py
```

The app opens automatically at `http://localhost:8501`

## 📁 Structure

```
portfolio_data_analyst/
  app.py            ← main application (all pages)
  requirements.txt  ← dependencies
  README.md
```

## 🗂️ Pages

| Page | Content |
|------|---------|
| 🏠 About | Bio, career timeline, key metrics |
| 📈 Projects | 4 interactive case studies with charts |
| 🛠️ Skills | Skill bars, pills, radar chart |
| 📬 Contact | Message form + links |

## ☁️ Deploy for free

**Streamlit Cloud (recommended)**
1. Push this folder to a GitHub repo
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your repo → Deploy

**Other options:** Railway, Render, Hugging Face Spaces

## ✏️ Customise

- Replace `"Your Name"` and placeholder links in `app.py`
- Update the `metrics`, `timeline_data`, and chart values with your real numbers
- Add your resume PDF to the folder and update the download link
